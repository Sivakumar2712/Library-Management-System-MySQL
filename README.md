# 📚 Library Management System | MySQL

## Project Overview
Designed and developed a relational database using MySQL to efficiently manage library operations, including student records, book inventory, and book issue transactions. Implemented database normalization, constraints, and SQL queries to ensure data integrity and efficient data retrieval.

## Key Features
- Student Management
- Book Management
- Book Issue & Return Tracking
- Primary & Foreign Key Relationships
- CRUD Operations
- SQL Joins and Aggregate Queries

## Database Tables
- Students
- Books
- Issued Books

## Technologies Used
- MySQL
- SQL

## SQL Concepts Implemented
- DDL (CREATE, ALTER)
- DML (INSERT, UPDATE, DELETE)
- Constraints
- Primary Key
- Foreign Key
- INNER JOIN
- Aggregate Functions
- ORDER BY
- GROUP BY
